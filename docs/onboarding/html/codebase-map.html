#Quick Ownership Guide

If You See A Bug In...Look First In...
Login or refreshservices/auth-service.js, middleware/authentication.js
API key accessservices/api-key-service.js
A REST endpointMatching file under api/v1/controllers/**, then the service it calls
A socket eventMatching file under sockets/**, then the service it calls
Class membershipservices/class-membership-service.js
Class state after restartservices/class-service.js, stores/class-state-store.js, database queries
